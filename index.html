Tentang Zyanest 360 Coffee

Zyanest 360 Coffee adalah konsep coffeeshop sederhana yang dihadirkan sebagai ruang berkumpul, belajar, dan berdiskusi bagi mahasiswa Teknik Informatika serta para pecinta kopi.

Website ini dibuat sebagai implementasi tugas pemrograman web dasar dengan memanfaatkan HTML semantik, CSS Flexbox & CSS Grid, serta interaktivitas JavaScript dasar.
